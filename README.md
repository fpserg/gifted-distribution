Статическая страница: вставляете ники Telegram и кошельки TON, вводите сумму, и она делится пропорционально балансам токена GIFTED
(`EQBenxtNSmGFbV8icHxXpSXk2NtpVsyb-JE0CZtBvIA6H1Nh`). Балансы запрашиваются из tonapi.io прямо в браузере.

Формат строки: `@ник: кошелёк` или `@ник: кошелёк баланс`, если баланс известен заранее.

Деплой: статический сайт без сборки, корень репозитория (`index.html`).
